# Demo recording guide

Record a 60–90 second walkthrough using Emu8086:

1. Show the main menu and identify the project as an educational 8086 Assembly suite.
2. Run the password checker with `Cyber@123`.
3. Compare TCP port 443 with TCP port 23 in the firewall simulator.
4. Encrypt `HELLO` using key 5, then decrypt with the same key.
5. Scan `malware exploit found in sample`.
6. Briefly show the source: rule arrays, procedures, and the substring-search routine.

Capture real application output. Useful screenshots include the main menu and one result from each module. Use demonstration inputs, and crop unrelated desktop content.
